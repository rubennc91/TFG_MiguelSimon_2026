# 05 · Dataset
- `dataset_jderobot/`: circuitos `montmelo_holonomic` y `counter_montmelo_holonomic` (`DATA_12_16`) del dataset de JdeRobot, cada uno con `data.csv` y las imágenes. El resto de circuitos se descarga del origen.
- `comprobacion_dataset/`: scripts que dibujan el dataset sobre vídeo (`comprobar_dataset_csv*.py`) y sus resultados.
